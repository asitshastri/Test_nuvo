# V0.1 Scope

> Status: **DRAFT, awaiting human sign-off** (TODO.md P0-05). Nothing here is approved yet.
> Evidence labels: `docs/01_EVIDENCE_AND_DECISIONS.md`. Governing documents: `CLAUDE.md`, `TODO.md`.

This document draws the **boundary** of V0.1. It does not design the ontology (P1-02 proposes and the human approves the label set) and it does not validate or select sources (P3-05 and P3-06 do that).

## 1. What V0.1 is

V0.1 is Phases 0 to 12 of TODO.md (D-002). Its goal (TODO.md P12 goal): show the whole system working, **source → scraper → raw → cleaning → corpus → NER → annotated document**, with a frozen test set and a model chosen by evidence.

Phases 13 to 16 (continuous pipeline, human-in-the-loop, continuous model improvement, advanced NLP platform) are the roadmap after V0.1 and stay out of scope. This document does not change that boundary.

## 3. Entity-type scope

| Layer | What it is | Decided where |

### Entity scope rules (from CLAUDE.md)

- Public OSINT is in scope; operationally sensitive detail is not excluded if it is public (CLAUDE.md hard rule 9).
- Focus: India and neighbours, major global security actors, NATO/EU/UN/SCO/Quad (CLAUDE.md Mission).
- Sub-entity layers such as relations, coreference, entity linking and event extraction are **not** V0.1 (NER only).

## 4. Language scope

- **V0.1 is English only** (TODO.md D-005, a human decision). Corpus, annotation and models are English.
- Every document still receives a language label with a confidence score (P5-05). Non-English documents are **set aside, not deleted and not silently treated as English**. Only documents labelled English continue to later steps.
- Mixed-language documents: language is recorded as detected; how to treat a document that is partly English is a P5-05 detail. UNKNOWN for now.
- Multilingual models, Hindi, Urdu, Bengali and other languages are **LATER**. CLAUDE.md says to test multilingual models seriously if Hindi/Urdu/Bengali exceed 15% of the corpus; with an English-only filter that condition does not arise in V0.1. FACT for context: in the source list 157 of 207 sources are `en` only and 28 more list `en` among several languages; 22 sources list no `en` at all (SRC-001 Wikidata and similar `multi` entries).
- No language expansion is proposed here.

## 6. Out of scope for V0.1

- Phases 13 to 16 and everything in their roadmap.
- Languages other than English; multilingual models.
- Relations, coreference, entity linking, event extraction.
- Paid, registration-gated and login-gated sources unless the human approves each one.
- Any access that bypasses robots.txt, terms, CAPTCHAs, logins or rate limits (TODO.md [COMP] rules and CLAUDE.md hard rule 4; the conflict with hard rules 1-2 is an open human question, see TODO.md Questions).
- Using inherited rows as final ontology, final gold, or final source selection.
- Touching the test set for tuning (CLAUDE.md hard rule 8).
